# animator


#Basketball Play Code Studio
A coding-based animation app where users create and explore basketball plays

#What it does
This project turns paths written in the editor into an animated basketball routes on a court. Blue routes represent player movement and yellow routes represent passes. Users can choose example drawings, edit the code, change the shape and speed sliders, and use Play, Pause and Restart controls to watch the animation.

#Extension 
My extension turns the Animator into a Basketball Play Code Studio. It includes a basketball court background, player and pass route colors, and different basketball plays. Each play is made from the same paths created by the user's draw code, so editing the code changes the movement shown on the court.
